## Owned files and exact interfaces

- explain.py: explain_row(plan, source, result, key, *, limit), the keyword-only exact-schema RowExplanation constructor, private schema checking, bounded trace builders and serialization
- _replay.py: _require_exact_replay(plan, source, result) returns only the matching canonical result SHA256 string. It requires the real enclosing A/B/C _required_inputs scope and fresh admission; it performs fresh admission itself before actual execute(plan, supplied source), compares every canonical result byte and returns after all replay result/iterator/helper frames have ended. Refusal/cancellation keeps its original code/type/identity. A canonical mismatch uses result_replay_mismatch
- tests/unit/test_explain.py and later separated explanation tests: genuine models and actual source/runtime/unit journeys; structural constructor fixtures carry no source or accounting authority

Existing _bundle_formats._recipe_json_chunks/_plan_json_chunks and _result._result_chunks are borrowed only under exact model validation and the complete operation scope. Their streams are exhausted or explicitly closed in the operation that owns them. No change to existing shared modules or public exports belongs to this slice. Native file dispatch remains a separately owned integration dependency; this implementation qualifies eager memory only.

## Validation and proof limits

Constructor validation checks exact primitive types before equality, exact field sets, homogeneous typed labels and width, all raw/direct integer nonnull rules, local stage policies and count-derived implicit weight sums, source index prefix/selection coherence, support bounds/order and final displayed linkage. It does not recover omitted source labels, prove adjacent-stage lineage, re-normalize weights, independently re-reduce values or establish scientific correctness. Public replay supplies exact same-engine consistency only.

Testing must retain error/cancellation objects with GC disabled; observe replay-buffer release before trace, true A/B/C lifetime, actual source consumption, no full plan serialization, no retained return handles, cap-before-allocation, exact omissions and first-global-stop behavior. Both actual public interpreter profiles are required. Immutable complete candidates, tests and mode/hash manifests are checkpointed before execution/review; evidence paths never overwrite prior red/green receipts.
